# Writing style — all replies and workflow docs

Applies to chat replies and every file a workflow stage writes: `proposal.md`, `plan.md`,
`tasks.md`, `review.md`, `test-report.md`, PR bodies/comments, `docs/**/*.md`.

Follow the `plain-professional-english` skill (`.claude/skills/plain-professional-english/SKILL.md`), kept compact:

- Answer / decision first, in one line.
- Precise professional words (B2+/C1), short sentences (≤ 25 words). No filler, no idioms.
- Prefer a diagram (Mermaid in docs, ASCII in chat), flow (`A → B → C`) or table over prose.
- Bullets: short, one idea each. Paragraphs ≤ 3 sentences.
- Cut background the reader does not need.
- Full forms in documents (do not); contractions fine in chat.
