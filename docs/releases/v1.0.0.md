# WordBuddy v1.0.0

First production-ready release. Released 2026-11-23. Targets: local Kubernetes (kind), and GHCR images (`ghcr.io/hunglu/wordbuddy-*:1.0.0`) for the single-host and Kubernetes production paths (ADR 0010).

v0.1.0 was never tagged. Its items ([v0.1.0.md](v0.1.0.md)) are first tagged in this release.
