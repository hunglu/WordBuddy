# WordBuddy v1.0.1

Patch release. Released 2026-11-27. Builds the 5 API images on GHCR that v1.0.0 could not (`ghcr.io/hunglu/wordbuddy-*:1.0.1`).

## Bug fixes

- Shared NuGet packages linked to the repo so CI can restore them — bugfix — #79 — [plan](../../.claude/plans/WB-79_link-shared-nuget-packages-to-the-repo-so-ci-can-restore-them/)
  - New package versions: Kernel 1.1.1, Application 1.0.1, Infrastructure 1.4.1, Contracts 1.4.1, Protos 1.0.1.
  - `images.yml` restores them with `GITHUB_TOKEN`; no stored PAT.

## Architecture decisions

None.

## Known issues

- Each shared package needs "Manage Actions access" → `WordBuddy` (Read) in its package settings. Linking the repo alone still gave 403. The docs do not state this step yet.
- The identity repository logs user email addresses (follow-up on #77).
- The UI nginx resolver returns 502 on kind.
- The SQL Server `sa` password generator in the runbook can produce a password with no digit.
- 11 Dependabot alerts on `main` (6 high).
