# Multilingual UI (English and Vietnamese)

Learners use the app's interface in English or Vietnamese.

## What it does

_Proposed — not on main yet._

The UI is available in English and Vietnamese. A learner picks a language with a switcher; the
choice is saved to their profile. Before login, the UI follows the browser language.

## Rules

- Supported languages: `en`, `vi`. Default: `en`.
- Only UI text is translated; lesson content stays as authored.
- **Child vs adult:** same behaviour for both.
